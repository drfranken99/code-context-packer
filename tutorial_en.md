
# 📦 CodeContextPacker (CCP) Step-by-Step Guide

## Step 1. Initial Dashboard

<img width="704" height="562" alt="1_init" src="https://github.com/user-attachments/assets/49bc4e44-750f-4e1c-b468-103592cefafe" />

This is the default state when you first launch the app. You can see a clean dashboard before any project is loaded.

## Step 2. Open Project Icon

<img width="704" height="562" alt="2_pointOpenFolderIcon" src="https://github.com/user-attachments/assets/5821cf87-10e5-4f8d-ae95-bc4402b93335" />

Click the **folder icon** located in the top bar or sidebar to initiate the project loading process.

## Step 3. Select Project Root

<img width="787" height="560" alt="3_chooseProjectRoot" src="https://github.com/user-attachments/assets/751419a7-9bc1-4155-85e4-f45e04b9d1b2" />

Select the **root folder** of the project you want to provide to the AI (e.g., Xcode, React, Spring, etc.).

## Step 4. Project Loaded View

<img width="704" height="562" alt="4_loadProject" src="https://github.com/user-attachments/assets/8513ffbb-6a60-4e0c-800b-205c1217d007" />

This view confirms the project has been successfully loaded. The left sidebar displays a **Finder-like file tree**, while the main area on the right shows the **merged text result** of the selected files.

## Step 5. Selective File Packing

<img width="704" height="562" alt="5_selectTargetFiles" src="https://github.com/user-attachments/assets/ce36bc07-f006-4f31-89d6-f35963ebc653" />

You don't have to include everything. Use the checkboxes to select only the **essential source code** needed for the AI. Excluding unnecessary libraries or configuration files helps save precious tokens.

## Step 6. Refresh Changes

<img width="704" height="562" alt="6_refreshChanges" src="https://github.com/user-attachments/assets/db89c072-09b0-4fec-a862-0089be102bf5" />

If you've modified your code in an external IDE like Xcode or VS Code, simply click the **Refresh button**. The changes will be immediately applied to the packed text on the right.

## Step 7. Copy Packed Context

<img width="704" height="562" alt="7_copyButton" src="https://github.com/user-attachments/assets/c395efff-7436-4705-9dda-0c8036279cc9" />

Click the **Copy icon** to save the entire packed text to your clipboard. Now you’re ready to paste it into your AI chat and start asking questions!

## Tip. Keyboard Shortcuts Tooltip

<img width="704" height="562" alt="8_tooltip" src="https://github.com/user-attachments/assets/f61e87ce-acae-4a47-b86e-e8a58de3c2fa" />

Click the **'?' button** to view a list of CCP-specific keyboard shortcuts designed to speed up your workflow.
