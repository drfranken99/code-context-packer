# CodeContextPacker
**AI 채팅용 코드 컨텍스트 큐레이션 및 패킹 도구**
CodeContextPacker는 프로젝트 디렉토리에서 필요한 파일만 골라 ChatGPT, Claude, Gemini 같은 AI에 최적화된 컨텍스트로 묶어주는 개발자용 도구입니다.
전체 저장소를 다 보낼 필요 없이, 필요한 파일만 시각적으로 선택해서 깔끔한 구조로 복사해 바로 붙여넣을 수 있습니다.
## 왜 CodeContextPacker인가요?
- 전체 레포를 다 넘기는 건 비효율적이고 노이즈가 너무 많습니다.
- CLI 도구들은 파일 선택을 세밀하게 제어하기 번거롭습니다.
- 수동 복붙은 작업 흐름을 끊고 일관성도 떨어집니다.
이 앱은 시각적인 컨텍스트 큐레이터 역할을 해서 이런 불편함을 해결합니다.
## 주요 기능
### 프로젝트 트리 사이드바
- Xcode 느낌의 계층 구조로 파일 브라우징
- 파일별 On/Off 토글 및 시각적 피드백 제공
- 선택된 파일은 하이라이트와 체크 표시로 바로 확인 가능
### 컨텍스트 패킹
- 선택한 파일만 결과물에 포함
- 루트 기준 상대 경로와 파일 본문 포함
- 사람이 읽기 편한 구분선으로 파일 간 경계 처리
### 통합 컨텍스트 미리보기
- 패킹된 결과를 한 페이지에서 확인
- 전체 선택(Cmd + A) 및 복사 지원
- AI 채팅창에 바로 붙여넣기 최적화
### 강제 새로고침
- 필요할 때 디렉토리를 다시 스캔해서 컨텍스트 재생성
## 컨텍스트 형식 예시
```

<파일 내용>

```
